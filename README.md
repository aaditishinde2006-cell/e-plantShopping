# Welcome to Paradise Nursery

## Project Overview

Paradise Nursery is an online plant shopping application where customers can explore houseplants, view product details, and manage their shopping cart.

## Features

- Browse plants organized into categories.
- View plant images, names, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease the quantity of cart items.
- Remove items from the cart.
- View individual item totals and the overall cart total.
- View a dynamically updated cart quantity indicator.
- Navigate between Home, Plants, and Cart.
- Display a checkout message.

## Technologies

- React
- JavaScript and JSX
- CSS
- Redux Toolkit
- React Redux

## Main Files

- `README.md` — Project information
- `AboutUs.jsx` — Company information
- `App.css` — Landing page and application styling
- `App.jsx` — Main application and landing page
- `CartSlice.jsx` — Shopping cart state management
- `ProductList.jsx` — Categorized plant listings
- `CartItem.jsx` — Shopping cart interface

## Objective

The project demonstrates the implementation of an interactive plant-shopping experience using React components and Redux state management.
